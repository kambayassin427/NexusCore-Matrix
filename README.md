# NexusCore Matrix — Universal Systems Panel

**NexusCore Matrix** is a high-performance, cross-niche workflow optimization platform. Designed through an ICT lens, it streamlines digital asset deployment, business operations, tactical combat sports analytics, and creative writing pipelines into a single, unified administrative dashboard.

---

## 🚀 Key Features

*   **Universal Systems Panel:** A centralized dashboard built to manage and deploy multi-niche operational workflows seamlessly.
*   **Global Affiliate Engine:** Built-in tools to dynamically generate, edit, and publish product cards with tracking and outbound affiliate referral links.
*   **Multi-Niche Architecture:** Pre-configured components tailored for:
    *   🥋 **Combat Sports & Analytics** (Tactical training & athletic gear data)
    *   ✍ **Creative Writing & Poetry Tools** (Digital structural frameworks)
    *   💻 **ICT, Coding & Business Infrastructure** (System automation pipelines)
    *   🌟 **General Lifestyle & Extra Products** (Curated performance tools)
*   **Intelligence Pipeline Integration:** Embedded data capture functionality for direct newsletter, WhatsApp, and email communication management.

## 🏁 Getting Started

### Prerequisites
*   Node.js (v18+ recommended) or your specific environment runner.
*   A package manager like `npm` or `yarn`.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd nexuscore-matrix
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory and add your admin credentials, media source settings, and referral webhook links:
   ```env
   PORT=3000
   ADMIN_PASSWORD=your_secure_password
   ```

4. **Run the Development Server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser to view the application.

## 🔒 Administrative Control

To access the product management tool and export system metrics:
1. Navigate to the `/admin` path or click the **Open Admin Portal** link.
2. Enter your credentials to view the **Global Affiliate Engine Panel**.
3. From here, you can fill out product specifications, publish new tracking components directly to the live view, or download your data using **Export Backup JSON**.
